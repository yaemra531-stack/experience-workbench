# 经验工作台（GitHub Pages 版）

基于用户提供的本地版改造。网页数据保存在当前浏览器的 localStorage，不会同步到 GitHub 或其他设备。清除网站数据、更换浏览器或设备可能丢失记录，请经常通过「设置与备份」下载 JSON 备份。

支持新建、整理、搜索、Markdown 文件上传或粘贴导入、Markdown 导出和 JSON 恢复。网页版不能扫描本机 Harness 文件夹或直接覆盖本地文件；使用上传和下载完成文件交换。原版 Python 本地服务保留在独立目录中。

网页内包含 Pyodide 0.27.7 运行时以运行原版解析和业务逻辑。首次加载可能需要一些时间。

## 创作工作台 V1

从侧栏进入「创作工作台」，短线用于记录案例、分析、迁移、发布与复盘，长线用于保存待实践或已实践的表达结构。短线可在案例分析中选择或新建一个长线结构，保存短线后可在长线查看关联作品。删除长线只解除关联，不删除短线。删除的创作记录无法在工作台内撤销。

创作数据单独保存在当前浏览器的 `creation-workbench-v1` 中，与经验记录分开。**经验备份不包含创作数据**；请在创作工作台左侧「备份创作数据」下载 JSON，并通过「导入创作备份」恢复；恢复仅增加不同 ID 的记录，不覆盖已有记录。数据不会跨浏览器或设备同步，浏览器存储有容量限制，清理网站数据可能导致丢失，建议定期备份。V1 的截图采用链接或文字备注，不保存图片文件。

本地检查：在本目录运行 `python3 -m http.server 8000`，浏览器打开 `http://127.0.0.1:8000/`，本地测试数据与线上浏览器数据分开。首次加载需等待内置运行组件。
